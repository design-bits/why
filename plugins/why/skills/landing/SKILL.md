# The landing report

Call the `landing` tool on the `designbits` MCP server (pass `since` as YYYY-MM-DD if the user names a date). Show its lines as they come: three lines and a link at most.

If a tripwire went off or is due, say which in one sentence and offer to look at it on the board. Mentions are counted from feedback people sent: they show what is loud, not what is common. Say so if the user reads them as proof.
